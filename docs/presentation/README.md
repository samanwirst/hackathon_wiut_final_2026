# Presentation assets

`VisionFlow-defense.pptx` is an eight-slide editable deck. `VisionFlow-fallback-demo.mp4`
is an actual recorded browser fallback; it is not a UI mock or model simulation.
Follow `../DEFENSE_SCRIPT.md` for the exact seven-minute flow.

The deck names experimental results and failed QA honestly. The six unique
synthetic held-out inputs are not natural footage. Eighteen timing observations
do not create eighteen independent quality samples. No Student is activated,
no cost savings percentage is claimed, and the closed rental performed no
remote inference. Update status only after the exact fresh review returns.

All PNG previews were generated and visually inspected using the artifact
presentation runtime; `VALIDATION.json` binds the PPTX and actual model panel.
The images under `assets/` are actual browser captures, not invented data.
The source `build.mjs` requires the separate `@oai/artifact-tool` ES-module runtime
used to author the deck; it is not an application dependency. Run it from an
environment providing that module. PowerPoint can directly edit the exported
text/shapes without the authoring runtime. Temporary layouts/previews stay local.
